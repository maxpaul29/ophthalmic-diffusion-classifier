# Results Directory Overview

This file documents the structure of the `results` directory and explains the main experiment groups, especially for `fundus-classifier` and `fundus-unet`.

## General layout

- `results/fundus-classifier/`: Contains the baseline ResNet-50 results for fundus classification.
- `results/fundus-unet/`: Contains U-Net based experiment results, including finetuning from Mogon pretraining and from-scratch training directly only on drusen data.
- `results/plot-scripts/`: Contains plotting scripts used to generate figures for the thesis results section and to create general visual outputs from experiment logs and data.
- `results/plots/`: Contains general plots created through plotting scripts.


## fundus-classifier

This folder holds the tested baseline model results for the fundus classifier.

- `results/fundus-classifier/res-net-50/`
  - `log_training_baseline_single_run.log`: log for the single-run baseline training of ResNet-50.
  - `log_training_baseline_cv.txt`: log for the cross-validation baseline training.
  - `cv_results.json`: cross-validation metrics summary for the baseline.

### Baseline variants

- `single run`: a single training experiment for ResNet-50.
- `cv`: 5-fold cross-validation training and evaluation for ResNet-50.

## fundus-unet

This folder separates the U-Net based experiments into two main categories:

### finetuned-model

This is the experiment where a U-Net model is finetuned after Mogon Phase-1 pretraining.

- `results/fundus-unet/finetuned-model/`
  - `single_run_results/`: finetuning & inference single run logs and plots.
  - `training_images_single_run/`: training images saved during the single-run evaluation phase.
  - `inference_images_single_run/`: images generated by `explain.py` during inference with the single run model.
  - `uncertainty_results_single_run/`: uncertainty evaluation results for the single run and plots.
  - `cv_results/`: results from the 5-fold cross-validation finetuning experiment, including plots.
  - `plot_loss_finetuned_model_single_run.py`, `plot_metrics_finetuned_model_single_run.py`: plotting scripts for finetuned-model single run loss and metrics.

#### Experiment meaning

- `single run` under `finetuned-model` is the 400-epoch finetune run for a model pretrained on Mogon.
- `cv` under `finetuned-model` is the 5-fold cross-validation finetuning experiment, where the model is finetuned across 5 folds.

### training-from-scratch

This is the experiment where the model is trained from scratch without Mogon pretraining.

- `results/fundus-unet/training-from-scratch/`
  - `single_run_results/`: logs for the single run from scratch.
  - `cv_results/`: logs from the 5-fold cross-validation from scratch run.
  - `training_images_single_run/`: training images produced during the evaluation phase of the from-scratch run.

#### Experiment meaning

- `training-from-scratch` means the model is trained without the Phase-1 Mogon pretraining step, using augmented Drusen images directly.

## Images and generated outputs

- `training_images_*`: always contains images saved during training after evaluation epochs.
- `inference_images_*`: contains images generated by `explain.py`, representing model explanations or inference outputs.

## uncertainty results

- `uncertainty_results_single_run/` contains results for uncertainty evaluation.
- This is similar to the Favero-style uncertainty analysis: it evaluates model uncertainty and produces outputs used for uncertainty-based result interpretation.

## plot-scripts

- `results/plot-scripts/plot_cv_accuracy.py`: plots cross-validation accuracy.
- `results/plot-scripts/plot_cv_f1.py`: plots cross-validation F1 scores.
- `results/plot-scripts/plot_difference_colorbar.py`: plots difference colorbars for visual comparison.
- `results/plot-scripts/plot_loss.py`: plots training loss curves.
- `results/plot-scripts/plot_metrics.py`: plots generic metric curves.
- `results/plot-scripts/plot_uncertainty_filtering.py`: plots uncertainty filtering results.

These scripts support the thesis results section and general visual evaluation of the model experiments.
