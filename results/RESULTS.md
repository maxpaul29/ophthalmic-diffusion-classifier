# Results Directory Overview

This file documents the structure of the `results` directory and explains the main experiment groups, especially for `fundus-classifier` and `fundus-unet`.

## General layout

- `results/fundus-classifier/`: Contains the baseline ResNet-50 results for fundus classification.
- `results/fundus-unet/`: Contains U-Net based experiment results, including finetuning from Mogon pretraining and from-scratch training directly only on drusen data.
- `results/general-plot-scripts/`: Contains general-purpose plotting scripts used to generate figures for the thesis results section from experiment logs and data.
- `results/general-scripts/`: Contains general-purpose scripts that are not plots, e.g. for aggregating cross-validation results.

Note: Phase-1 pretraining (Mogon, unconditioned reconstruction on ~400,000 public fundus images) runs in a separate infrastructure and is not part of this results tree; its logs/checkpoints live in the `drusen-mogon` branch instead.

## fundus-classifier

This folder holds the tested baseline model results for the fundus classifier.

- `results/fundus-classifier/res-net-50/`
  - `hold_out_results/`: `training_log.log` and `inference_result.json` for the hold-out split baseline training/evaluation of ResNet-50.
  - `cv_results/`: `10_fold_cv_training_log.log` and `10_fold_cv_summary.json` for the 10-fold cross-validation baseline training and evaluation.


## fundus-unet

This folder separates the U-Net based experiments into two main categories:

### finetuned-model

This is the experiment where a U-Net model is finetuned after Mogon Phase-1 pretraining.

- `results/fundus-unet/finetuned-model/`
  - `hold_out_results/`: finetuning & inference logs, plots, training/inference images, and uncertainty results for the hold-out run.
    - `training_log.log`: finetuning log.
    - `inference_result_n*.json`, `inference_n51_log.log`: inference results/log at different `EVALUATION_PER_STAGE` sample counts.
    - `plots/`: loss/metric plots and their generating scripts (`plot_loss_finetuned_model_single_run.py`, `plot_metrics_finetuned_model_single_run.py`).
    - `training_images/`: training images saved during the evaluation phase (`active`/`inactive` subfolders).
    - `inference_images/`: images generated by `explain.py`, organized by sampling steps and cfg/`from_t` combination.
    - `uncertainty_results_n501/`: uncertainty evaluation results and plot for the single run.
  - `cv_results/`: results from the 10-fold cross-validation finetuning experiment (restricted to the hold-out split's exact image pool, see `dataset/splits/SPLITS.md`).
    - `10_fold_cv_training_log.log`: training log covering all 10 folds.
    - `10_fold_cv_summary_n501.json`, `10_fold_cv_summary_n51.json`: aggregated mean±std metrics across folds, at different `EVALUATION_PER_STAGE` sample counts.
    - `plots/`: per-fold accuracy/F1 plots and their generating scripts (`plot_cv_accuracy_finetuned_model.py`, `plot_cv_f1_finetuned_model.py`).

### training-from-scratch

This is the experiment where the model is trained from scratch without Mogon pretraining.

- `results/fundus-unet/training-from-scratch/`
  - `hold_out_results/`: training log, inference result, plots and training images for the single hold-out-split from-scratch run.
  - `cv_results/`: `10_fold_cv_training_log.log` and `10_fold_cv_summary_n501.json` for the 10-fold cross-validation from-scratch run.

## Images and generated outputs

- `training_images/`: always contains images saved during training after evaluation epochs (`active`/`inactive` subfolders).
- `inference_images/`: contains images generated by `explain.py`, representing model explanations or inference outputs.

## uncertainty results

- `uncertainty_results_n501/` contains results for uncertainty evaluation.
- This is similar to the Favero-style uncertainty analysis: it evaluates model uncertainty and produces outputs used for uncertainty-based result interpretation.

## general-plot-scripts

- `results/general-plot-scripts/plot_cv_accuracy.py`: plots cross-validation accuracy.
- `results/general-plot-scripts/plot_cv_f1.py`: plots cross-validation F1 scores.
- `results/general-plot-scripts/plot_accuracy_vs_steps.py`: plots accuracy against the number of classification/sampling steps.
- `results/general-plot-scripts/plot_difference_colorbar.py`: plots difference colorbars for visual comparison.
- `results/general-plot-scripts/plot_loss.py`: plots training loss curves.
- `results/general-plot-scripts/plot_metrics.py`: plots generic metric curves.
- `results/general-plot-scripts/plot_uncertainty_filtering.py`: plots uncertainty filtering results.

These are the general-purpose templates that the experiment-specific plotting scripts inside each `hold_out_results/plots/` or `cv_results/plots/` folder are adapted from.

## general-scripts

- `results/general-scripts/aggregate_cv_results.py`: aggregates a k-fold cross-validation run's per-fold inference results into mean±std per metric, the number actually reported in the thesis instead of a single fold's point estimate.
